# Word-level sync

O Presidente da República sanciona a lei. A lei altera a remuneração dos
servidores e dos empregados públicos federais, e o texto segue quebrado em
linhas para provar que a correspondência atravessa a quebra.

O termo **efetivos** aparece aqui, e o mesmo efetivos aparece de novo logo
depois, para que uma busca ingênua escolha a ocorrência errada.

Uma palavra com escape: \*literal\* e uma entidade: &amp; e outra &copy; no meio.

Um link para o [Planalto](https://www.gov.br/planalto) e um `código embutido`
no meio da frase.

A fórmula $E = mc^2$ fica no meio do parágrafo, entre palavras comuns.

> [!NOTE]
> Este é um alerta com **destaque** e texto suficiente para uma linha.

- [ ] tarefa pendente
- [x] tarefa concluída

| Cargo | Remuneração |
| --- | --- |
| Fiscal | R$ 10.000 |
| Analista | R$ 8.000 |
