# The application webview runs under a content security policy

**Status:** accepted
**Date:** 2026-10-20

## Context

`src-tauri/tauri.conf.json` shipped `"csp": null`, so the editor webview had no
content security policy. The Markdown and AsciiDoc previews sanitise with
DOMPurify, the HTML document runs in an opaque sandbox, and the asset protocol is
scoped to `**` because a document may reference an image anywhere on disk. None
of those boundaries is a substitute for a policy on the application origin: a
single sanitiser bypass, a malicious dependency, or a future `innerHTML` path
would otherwise execute with the full IPC surface available to the editor.

The policy must keep the application working: Vite emits a module script and a
stylesheet under `/assets`, CodeMirror and KaTeX insert inline styles, the Typst
grammar uses WebAssembly, the PDF.js worker is a module worker, images come from
the asset protocol, remote images, `data:` and `blob:`, the HTML guest is an
iframe served by `mdraft-preview`, and Tauri's IPC is reached over `ipc:` /
`http://ipc.localhost`.

## Decision

The webview uses this policy in `app.security.csp`:

- `default-src 'self'`
- `script-src 'self' 'wasm-unsafe-eval'` — bundle scripts and the Typst grammar;
  no inline script, no `eval`, no remote script.
- `style-src 'self' 'unsafe-inline'` — the bundled stylesheet plus the inline
  styles CodeMirror, KaTeX and Mermaid create at runtime.
- `img-src`, `media-src`: `'self'`, the asset protocol, `data:`, `blob:`, and
  `http:`/`https:` for images a document links.
- `font-src 'self' data:`.
- `connect-src 'self' ipc: http://ipc.localhost` — the bundled-font `fetch()` used
  by export and Tauri's IPC. No remote `connect-src`: downloads happen in Rust.
- `frame-src 'self' mdraft-preview: http://*.invalid` — the HTML guest only.
- `worker-src 'self' blob:` — the PDF.js worker.
- `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`.

The HTML guest keeps its own per-document CSP from `html_preview.rs`; the parent
policy only decides that the guest may be framed.

## Consequences

A new remote script, stylesheet, font or `fetch()` target must be named in the
policy deliberately; a feature that works in `npm run dev` can still be blocked
in the packaged application. `connect-src 'self'` is required for the export
font embedding path, which fetches the woff2 files from `/assets`.

Tauri serves the policy as a response header, not a `<meta>` tag. A check that
only queries `meta[http-equiv="Content-Security-Policy"]` reports `null` while
the policy is active; prove enforcement by appending an inline script and
checking that it did not run.

The asset protocol remains scoped to `**`, because the editor must display
images beside arbitrary documents. That is now a narrower exposure: `connect-src`
does not include the asset protocol and `frame-src` does not either, so a document
cannot read an arbitrary file through `fetch()` or frame it. Tightening the asset
scope would require a per-document runtime allow-list.
