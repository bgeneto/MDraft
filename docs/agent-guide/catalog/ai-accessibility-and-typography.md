# AI Assistant, Read Aloud and typography

The AI Assistant (unit, mock and opt-in live), Read Aloud, the bundled and
installed typefaces, and the licence check. A change to `src/ai/`,
`src-tauri/src/ai/`, `src/read-aloud.ts`, `src/fonts.ts` or `src/preferences.ts`'s
typography rows belongs here.

The traps are in
[../traps/ai-accessibility-and-typography.md](../traps/ai-accessibility-and-typography.md).

## Test harnesses

Every harness here needs the app already running with CDP enabled (see
[../testing.md](../testing.md#running-the-cdp-tests-correctly)) **and the right
document loaded**. The port is always `argv[2]` and defaults to `9222`.

| Script | Arguments | Needs this document | Proves |
| --- | --- | --- | --- |
| `typography-test.mjs` | `[port]` | any | Screenshots text with each OpenType feature off and on and compares pixels, then asserts the six-preset matrix, that the four new body faces produce different images, and the Semibold weights; also opens the installed-font picker, selects a family the host actually reports, and exercises Custom, a per-preset face edit, its round trip, Reset and the saved `typographyPreset`/`presetOverrides` diff. Width cannot measure a monospaced face, so nothing narrower would work |
| `licence-test.mjs` | `[port]` | any | Opens *Font licences* and looks for the thirteen OFL texts in the rendered document. Searching the executable cannot answer this: the frontend bundle is compressed inside it |
| `ai-unit.mjs` | — | none — runs without the application | The AI catalog and search, paragraph expansion, Continue spacing, block insertion, parameters, stale targets, session-history insertion/replacement/titles/previews/ages, button geometry, the shared combo filter, the language search across aliases and accents, the word diff and the frontend history turn cap that leaves token trimming to Rust |
| `ai-assistant-test.mjs` | `[port]` | `samples/feature-tour.md` | The icon-only draggable button and its launch anchor, its own right-click menu, the palette, the configurable Context limit and its token refusal, the panel's token count, representative actions and parameters, streaming, Stop, a 401, Anthropic, model fetch, stale targets, a tab switch, appearance and key hygiene, against a local mock |
| `ai-live-test.mjs` | `[port]` | `samples/feature-tour.md` | The same actions against the real Qwen endpoint, reading `MDRAFT_AI_E2E_*`; opt-in, and `MDRAFT_AI_LIVE_OPTIONAL=1` makes a missing key a visible SKIP |
| `read-aloud-test.mjs` | `[port]` | `samples/feature-tour.md`; opens `samples/html-tour/index.html` and `samples/word-sync.md` | The editor menu's Read Aloud entries, the status chip and its position, the queue advancing to the next sentence, Stop from the menu and from the chip, the HTML tab disabling both entries with a reason, a Portuguese document selecting an installed Portuguese voice, and the voice and rate saved through Preferences. A real CDP press comes first: `speak()` needs sticky user activation, which a synthetic click does not grant |
| `read-aloud-unit.mjs` | — | none — runs without the application | The sentence splitter, the voice choice by saved name and document language, English/Portuguese detection, declared `lang`, the dictionary vote and its timeout, the utterance's language through a fake `speechSynthesis`, the queue's state machine (stop mid-queue, a late `onend`, `canceled` versus a real failure, a synchronous backend) and the Preferences note |
