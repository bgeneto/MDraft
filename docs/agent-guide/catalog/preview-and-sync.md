# Preview, word sync and rendering performance

The Markdown, AsciiDoc, Typst and HTML previews, the source maps behind word
sync, document zoom, and the performance probes. A change to `src/markdown.ts`,
`src/asciidoc-preview.ts`, `src/html-preview.ts`, `src/typst-*.ts` or the scroll
solver belongs here.

The traps these suites keep rediscovering are in
[../traps/preview-and-sync.md](../traps/preview-and-sync.md).

## Test harnesses

Every harness here needs the app already running with CDP enabled (see
[../testing.md](../testing.md#running-the-cdp-tests-correctly)) **and the right
document loaded**. The port is always `argv[2]` and defaults to `9222`.

| Script | Arguments | Needs this document | Proves |
| --- | --- | --- | --- |
| `dom-smoke.mjs` | `[port]` | `samples/feature-tour.md` | Rendering, pane sync, preferences, search, toggles, math, fonts, status icons, blink behaviour |
| `word-sync-test.mjs` | `[port]` | `samples/word-sync.md`; writes temporary Markdown, AsciiDoc and Typst list fixtures and opens the built-in Markdown Reference | The fragment map, preview → source and source → preview, atomic code and formula spans, word snapping, no scroll, Escape, typing clears, and the documented fallbacks (alert, missing fragment). Multiline lists in Markdown, AsciiDoc and Typst Document assert the *exact source offset* of the painted word for first lines, continuation lines, ordered/task/nested/block-quoted items and the second occurrence of a repeated word, plus a selection across items and the block blink still present beside the word correspondence |
| `audit-document.mjs` | `[port] [label]` | any — `label` names it in the output | Block/anchor counts, table and code-fence totals, KaTeX errors, stray `$` in prose |
| `math-render-check.mjs` | `[port]` | `docs/samples/physrevb_70_035307.md` | That fonts actually load and that fractions and radicals have real geometry |
| `html-preview-test.mjs` | `[port]` | `samples/html-tour/index.html` | The guest iframe, its sandbox and IPC boundary, local CSS/images/modules, sync, blink, scripts-off, outline, the return to Markdown and the HTML tab coming back. It connects to the iframe target as well as the page |
| `preview-zoom-test.mjs` | `[port]` | `samples/export-tour.md`; opens the AsciiDoc, Typst and HTML fixtures | Document zoom geometry in Split/Preview-only/Source-only, AsciiDoc, Typst Document, Typst Pages and the HTML guest; a zoomed word sync; reset and Content Width; a 150% screenshot |
| `preview-performance-test.mjs` | `[port]` | any; opens generated Markdown and AsciiDoc documents | Real keydown/char/keyup, nonempty input samples, actual worker overlap, p50/p95/p99/max, the final correct preview and a deliberate-block positive control. `MDRAFT_PREVIEW_EXTREME=1` selects the 10.8 MB/72,000-paragraph CRLF fixture |
| `typst-page-map-unit.mjs` | — | none — runs without the application | The Typst Pages source map's one-word rule: identical neighbours paint nothing, a unique window picks the occurrence, ligatures and soft hyphens fold, generated text stays unmapped. A multiline list keeps every word of a first line and its continuation on its own source line in both directions, and repeated list words keep their own lines |
| `html-source-map-unit.mjs` | — | none — runs without the application | The HTML text-node rule: decoded-to-raw offsets across entities and CRLF, the sample check that fails closed, and the index that selects one node under a stamp |
| `block-map-unit.mjs` | — | none — runs without the application | The block-level source map and Typst line annotation: folded index mapping, per-node alignment across substitutions and smart punctuation, gap block fallback, Typst comments/rules/math/code/tables, and `#lorem` exclusion. Multiline list nodes map their exact words, four repeated prefixes keep four occurrences, and an ordered continuation is exact |
| `typst-preview-test.mjs` | `[port]` | `samples/typst-pages.typ`; writes a temporary Typst list fixture and opens the built-in Typst Reference | The Pages view is the compiler's PDF drawn by PDF.js with selectable text, both columns and two pages; a single click paints the source paragraph, a repeated word in a later line or the right column maps that occurrence, generated `#lorem` paints nothing, the view bar does not blur the page, and switching back disposes the PDF view. Document gets the same word-map checks plus inline-math paragraphs, tables and code blocks, and a single click does not paint a word there. A wrapped list item in the reference maps its first and continuation lines, and a Pages list item maps a text-layer click to its own source line and back through `CSS.highlights` |
