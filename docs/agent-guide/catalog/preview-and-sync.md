# Preview, word sync and rendering performance

The Markdown, AsciiDoc, Typst and HTML previews, the source maps behind word
sync, document zoom, and the performance probes. A change to `src/markdown.ts`,
`src/asciidoc-preview.ts`, `src/html-preview.ts`, `src/typst-*.ts` or the scroll
solver belongs here.

The traps these suites keep rediscovering are in
[../traps/preview-and-sync.md](../traps/preview-and-sync.md).

## Test harnesses

Every harness here needs the app already running with CDP enabled (see
[../testing.md](../testing.md#running-the-cdp-tests-correctly)) **and the right
document loaded**. The port is always `argv[2]` and defaults to `9222`.

| Script | Arguments | Needs this document | Proves |
| --- | --- | --- | --- |

| `word-sync-test.mjs` | `[port]` | `samples/word-sync.md`; writes temporary Markdown, AsciiDoc and Typst list fixtures and opens the built-in Markdown Reference | The fragment map, preview → source and source → preview, atomic code and formula spans, word snapping, no scroll, Escape, typing clears, and the documented fallbacks (alert, missing fragment). Multiline lists in Markdown, AsciiDoc and Typst Document assert the *exact source offset* of the painted word for first lines, continuation lines, ordered/task/nested/block-quoted items and the second occurrence of a repeated word, plus a selection across items and the block blink still present beside the word correspondence |
