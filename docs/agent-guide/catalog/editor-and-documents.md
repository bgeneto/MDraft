# Editor, documents and application chrome

Editor input, the document lifecycle, tabs, favorites, menus, shortcuts, paste,
images and the app-free unit layers that back them. These are the suites a change
to `src/main.ts`, `src/editor.ts`, `src/sessions.ts` or `src/preferences.ts`
usually needs.

The governance rules for adding a script are in
[../scripts.md](../scripts.md#conventions-for-new-test-scripts); the test order
is in [../testing.md](../testing.md#the-order-layers-run-in).

document loaded**. The port is always `argv[2]` and defaults to `9222`.
